Database Design, Architecture & Relational Schema

Slide 7 Architecture & Slide 8 ER Diagram from Project Presentation

👤 Students Master Entity
student_id (INT) PRIMARY KEY
prn (VARCHAR) UNIQUE
name (VARCHAR) NOT NULL
email (VARCHAR) UNIQUE
branch (VARCHAR) CSBS
semester (INT) CHECK (1..8)
📖 Subjects Master Entity
subject_id (INT) PRIMARY KEY
subject_code (VARCHAR) UNIQUE
subject_name (VARCHAR) NOT NULL
credits (INT) CHECK (credits > 0)
semester (INT) CHECK (1..8)
📅 Attendance 1-to-N Link
attendance_id (INT) PRIMARY KEY
student_id (INT) FK -> Students
subject_id (INT) FK -> Subjects
lecture_date (DATE) NOT NULL
status (VARCHAR) 'Present' / 'Absent'
UNIQUE (student, subject, date) CASCADE
📝 Assignments Task Tracker
assignment_id (INT) PRIMARY KEY
student_id (INT) FK -> Students
subject_id (INT) FK -> Subjects
title (VARCHAR) NOT NULL
due_date (DATE) NOT NULL
status (VARCHAR) DEFAULT 'Pending'
📋 Exams Evaluation
exam_id (INT) PRIMARY KEY
subject_id (INT) FK -> Subjects
exam_type (VARCHAR) In-Sem, End-Sem, UT
exam_date (DATE) NOT NULL
max_marks (DECIMAL) CHECK (max > 0)
🏆 Marks Score Record
mark_id (INT) PRIMARY KEY
student_id (INT) FK -> Students
exam_id (INT) FK -> Exams
marks_obtained (DECIMAL) CHECK (marks >= 0)
UNIQUE (student_id, exam_id) CASCADE
